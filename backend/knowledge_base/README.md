# Knowledge Base

This directory contains the source documents used by the Campus Expert knowledge system.

## Structure

- **official/** — Information obtained from official VIT AP / university sources (academics, attendance, exams, hostel, transport, faculty, campus, regulations, placements, medical).
- **student/** — Curated student and community information (clubs, campus tips, hostel tips, FAQs). Content in this folder must **not** be presented as official university policy.

## Guidelines

1. Documents should preserve their original source information (e.g. source name, URL, date obtained) so answers can eventually provide citations.
2. Do not place passwords, API keys, credentials, private student information, or any other secrets in this directory.
3. Keep `official/` and `student/` content clearly separated so the distinction between verified university information and community-contributed information is never lost.

This directory currently contains only the folder structure. Documents will be added in a later phase.
